# Delivery squad

## Purpose

Implement a defined product change in the existing repository while preserving its conventions and user-visible behavior outside scope.

## Compose from

- `engineering-delivery`
- `system-architecture` for changes crossing system or domain boundaries
- `security-review` for security-sensitive changes

## Handoff

List changed behavior, affected components, checks actually run, known gaps, and any decision or deployment still required. Ask for unresolved product rules instead of inventing them.
