# Acceptance criteria template

## Outcome

What user or operational result must be observable?

## Preconditions

What data, permission, account state, or configuration is required?

## Scenarios

- Given …, when …, then …
- Given an invalid or unavailable state, when …, then …
- Given a retry, duplicate action, or recovery, when …, then …

## Evidence

Which UI state, API response, stored value, log, or test demonstrates the result?

## Open decisions

What remains undecided, who owns it, and does it block implementation or release?
