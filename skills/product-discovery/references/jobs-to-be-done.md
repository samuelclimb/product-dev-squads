# Jobs to Be Done

Use this lens when a feature request names a solution but the user goal or reason for choosing it is uncertain.

Describe:

- **Situation:** what is happening when the need appears?
- **Progress:** what is the user trying to accomplish?
- **Constraints:** what makes the current approach difficult or risky?
- **Alternatives:** what do users do today, including workarounds?
- **Desired outcome:** what observable change would count as improvement?

Keep statements grounded in evidence. A job statement is a framing hypothesis until validated with users or behavioral data. Avoid treating a persona label as evidence of motivation.
