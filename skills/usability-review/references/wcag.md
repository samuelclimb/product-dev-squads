# Accessibility review with WCAG

Use WCAG 2.2 as a reference for applicable web content. Check only what the inspected platform and available tools can establish; label the rest unverified.

Relevant areas often include text alternatives and names, keyboard operation, focus order and visibility, contrast, error identification, status messages, target size, and reflow. Include assistive technology or mobile-specific checks when the product and environment support them.

Source: [W3C WAI — What's New in WCAG 2.2](https://www.w3.org/WAI/standards-guidelines/wcag/new-in-22/).
